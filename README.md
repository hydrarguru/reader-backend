# Reader API
This repository contains the source code for Reader API / Reader backend that powers [Reader](https://github.com/hydrarguru/reader).

A REST API featuring JWT login and CRUD operations for users, communities, & posts. Deployed at https://reader-api.fly.dev, with Swagger docs at [/api-docs](https://reader-api.fly.dev/api-docs).

## Tech Stack:
- TypeScript + Express.js.
- Sequelize ORM.
- MySQL Database.
- JWT auth via jose.
- Swagger for API documentation.
- Hosted on Fly.io.
